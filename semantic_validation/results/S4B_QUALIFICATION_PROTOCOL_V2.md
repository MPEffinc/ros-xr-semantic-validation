## New campaign and finite attempts

The independent CP4 qualification campaign contains one named configuration cell per `(Docker D1, baseline, information regime, monitor mode)`: B0 original, observational B0-shim, B1 I_NATIVE/I_FULL, official B2-native I_NATIVE/I_FULL, separately labelled official B2-composed I_NATIVE/I_FULL, B3 I_NATIVE/I_FULL. B0 has no synthetic defense state. Each cell receives **one initial integrated setup attempt plus at most two setup-only retries**, counted from its first CP4 trial; failed attempts remain visible. CP3 attempts do not count in CP4 and CP4 does not change CP3's exhausted verdict. A functional policy violation is a result, never a reason to retry for success. A code, policy, fixture, analysis-rule or topic-path change after the CP4 freeze invalidates affected cells and requires a new preregistered version/freeze rather than a silent retry. Environment-only correction within the fixed code/configuration can consume a retry; record exact before/after environment diff. When a cell's attempts are exhausted, mark it BLOCKED and do not automatically create CP5 or a new campaign.

The first CP4 **runtime** may occur only after a separate commit-push freezes: this protocol and digest; all execution code/configuration and source diff; official ROSMonitoring revision/generated source; pinned dependencies/image ID; fixture and normalized fixture hash; B0/B1/B2/B3 variants; sender/launcher/probe/analysis; monitor property/remaps; per-participant clock/start ACK; retry ledger and failure classifications. Before that commit, only read-only source inspection and short non-Gazebo preflight tests may run. Preflight corrections must be included in that freeze; no post-outcome selection is allowed. Runtime and formal results use separate roots and cannot be pooled with preflight or CP3.

## Mandatory non-Gazebo preflight

1. **Sender:** run a loopback fake receiver and a controlled barrier with the exact D1 sender. Require indices 0–119 exactly once, 120 full wire payloads, same normalized fixture SHA and phase order as CP3, `sender.done` only after final send, and zero negative sleeps. Record each sample's scheduled and actual monotonic times, late count and worst lateness; compare matched fixtures to the frozen 5 ms source-index schedule rule. A nonnegative `sleep` clamp alone is insufficient. Inject a failed socket/child and require the parent launcher to return nonzero. These are harness tests, not ROS/Gazebo evidence.
2. **Oracle:** use the official TLOracle/Reelay abstraction/property on valid active, ungripped neutral, original neutral, reference, invalid tracked, stale, future, old generation and missing metadata fixtures. Assert expected verdicts. For I_NATIVE, age/generation remain UNOBSERVABLE; do not assert a full-policy check from absent fields. Bind I_FULL state and ROS payload from the same source object and verify hash-preserving restore. No adapter may independently check validity/freshness/recovery.
3. **Monitor/remap:** inspect the actual official generator output: `_mon` subscription and base publication match the configured input/output; downstream must have only the post-filter base publisher and no bypass. Require oracle startup/positive verdict before ACK. Confirm generated monitor source hashes, official pinned revision and filter action; toy monitor evidence alone is insufficient.
4. **Launcher/probe:** static/isolated child-failure injection returns nonzero for sender/monitor/oracle/recorder; normal child completion must not be hidden by a successful recorder. Require full 120-index/source-done check, named DDS endpoint/recorder ACK, active Servo/controller, initial joint pose/velocity/drift, source index zero, per-participant boot ID/time namespace and host-bracketed monotonic offset uncertainty <=1 ms. Fixed sleeps may allow startup but never substitute for ACK. A real ROS/Gazebo start must later validate these same checks; a primitive test alone is not enough.

Preflight failure may be corrected **only before** the CP4 freeze and must be retained with command, stdout/stderr, failed assertion and diff. If any mandatory preflight remains failed or UNKNOWN, do not start integrated runtime.

## Integrated qualification and formal-comparison gate

After freeze, run fresh trial-owned Gazebo-only containers with identical fixture, initial pose, source schedule, controller/Servo settings and information regime. Record the real original receiver/mapper/bridge, generated official B2 monitor and TLOracle decision path, ROS and Servo callback, controller output, `/joint_states`, DDS/clock/start ACK and all child exits. Require full source 0–119, no unintended normal-input block, reference acquisition, active control, unique exact source/command→Servo-callback join where claimed, interval-level controller output and Gazebo movement >0.01 rad. Do not infer individual controller/joint parentage from timing proximity. B2-native failure behavior remains separate from B2-composed health stop; composed success is not an intrinsic ROSMonitoring feature. A normal D1 run without a fault does **not** prove B2-composed stop functionality; that remains a separate requirement where the frozen protocol calls for it.

Prior CP1/CP2 B0-shim equivalence can be reused only for the same observer/transport configuration. A changed CP4 path requires its own matched B0/shim pair under the frozen 5 ms timing and 0.02 rad final-joint rules. All participant clocks, graph, recorder, source index and controller state must be ACKed before barrier release. Qualification PASS for one regime or arm never substitutes for another.

Only after **all** D1 mandatory cells and applicable stop/clock/lineage gates PASS, create and commit-push a **separate formal-comparison freeze** with random seed 20260922 full five-repeat schedule, implementation/config/fixture/oracle/analysis hashes and trial ordering. Formal B0–B3 may then run under XRROS-S4-1.0.0 without changing policy or selecting favorable repetitions. If any prerequisite is BLOCKED/INVALID/UNKNOWN, D1 formal remains NOT_STARTED. Other Docker/OpenVR cases need their own extra condition-specific qualification and may not inherit D1's verdict. S5 requires sufficient valid formal comparisons; S6/S7 are out of scope.
